# Project Janus

A collection of intentionally vulnerable web applications you can run locally to practice ethical hacking. Learn to exploit plain text password storage, SQL injection, and brute force hash cracking in a safe, legal environment. Perfect for beginners learning web security fundamentals.

> **Disclaimer:** This project is for **educational purposes only**. Only use these techniques on systems you own or have explicit permission to test. The author is not responsible for any misuse of this material.

---

## What You Will Learn

Project Janus includes **3 different vulnerable websites**, each one demonstrating a single real-world vulnerability so you can see exactly how they appear in practice:

### Website 1 – Plain Text Passwords
See how some websites store user passwords in plain text with no hashing or encryption. Learn why this is dangerous and how an attacker can exploit it if they gain access to a database.

### Website 2 – SQL Injection
Explore one of the most well-known web vulnerabilities. Learn how unsanitized user input can allow an attacker to manipulate a database, bypass login pages, and extract sensitive data.

### Website 3 – Brute Force Hash Cracking
Discover how weak password hashes can be cracked using brute force techniques. Learn why strong hashing algorithms and salting matter.
